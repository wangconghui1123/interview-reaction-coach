# 阶段 5 提取训练与 331

## 目标

把“题→标签→素材”练成“题→素材”，让用户 3 秒开口。

## 两个动作

- 同素材，多换题：最熟的 3 段经历，每段连续回答 3 道不同题。
- 同题目，多换素材：同一道题，用两段不同经历各答一次。

## 331 训练法

- 3 秒开口：只留少量关键词，3 秒到就开口。
- 每题 3 遍：第一遍允许磕巴，第三遍才算稳定。
- 只练最卡的一下：回听后找到瓶颈，下一遍只针对该处。

## 判断加提取

给用户一道题，让用户先说：这题我要证明什么？我拿什么证明？然后再完成长回答。

## 阶段完成条件

最熟的 3 段经历各能回答至少 3 道题；没练过的题能在 5 秒内说出证明目标和证据；每题达到结论、细节数字和目标时长；用户完成时间、语速和情绪自查。
