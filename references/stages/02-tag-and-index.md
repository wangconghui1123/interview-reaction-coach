# 阶段 2 贴标签与建立索引

## 目标

让一段经历拥有多个检索入口，听到题目后可以快速定位素材。

## 三维标签

每段经历从以下三维各选 3–5 个真实标签：

- 能力：解决问题、团队协作、沟通说服、项目推进、数据分析、学习适应、创新、抗压、领导力、组织协调。
- 场景：社团运营、实习、项目、比赛、课程、从 0 到 1、预算有限、跨团队协作、时间紧。
- 高频词：困难、主动、创新、合作、压力、结果、学习、说服、资源、用户。

只使用用户能讲出细节的标签。把相近词合并成词族，如“困难/挑战/突发情况”归入“解决问题”。

## 训练动作

1. 给每段经历贴三维标签。
2. 建立“经历×标签”对照表。
3. 汇总个人素材索引：每个词族列出能回答的经历编号。
4. 随机给出一个词族，让用户在 3 秒内说出可用经历编号和关键词。

## 阶段完成条件

每段至少有能力、场景、高频词各 3 个；个人索引完成；随机抽词时能快速定位至少一段素材。没有素材的词族记录为盲区，后续补充经历或暂不使用。
