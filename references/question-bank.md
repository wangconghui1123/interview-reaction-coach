# 题库

## 有经历题

1. 讲一次你负责组织一件事的经历。
2. 你最有成就感的一件事是什么？
3. 讲一次你主动推动某件事的经历。
4. 讲一次你解决难题的经历。
5. 你在团队里通常扮演什么角色？
6. 讲一次你和别人发生分歧的经历。
7. 讲一次你坚持做成一件事的经历。
8. 讲一次你快速学习新东西的经历。
9. 你最近一次失败是什么，怎么处理的？
10. 为什么想做这个岗位？

## 观点题

1. 你怎么看待 996？
2. 你觉得 AI 会取代很多岗位吗？
3. 你有考公考编的想法吗？
4. 你怎么看待年轻人频繁跳槽？
5. 你觉得什么样的团队适合你？

## 场景题

1. 工作中遇到不会的事情，你怎么办？
2. 压力大的时候，你怎么调节？
3. 如果入职后发现岗位和预期不一样，怎么办？
4. 你的方案被领导否决了，怎么办？
5. 团队里有人不配合你，怎么推进？

## 即兴题

1. 如果让你重新做一次那个项目，你会怎么改？
2. 你刚才说的经历，有没有失败的地方？
3. 入职后发现岗位和预期完全不一样，怎么办？
4. 你的方案被领导否决了，怎么办？
5. 团队里有人不配合你，怎么推进？
